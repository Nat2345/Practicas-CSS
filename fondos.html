Los fondos permiten cambiar la apariencia de los elementos mediante colores, imagenes, degradados y diferentes posiciones

1. Background-color: sirve para establecer un color de fondo

fondo azul claro

2. Background-image: sirve para colocar una imagen como fondo

3. Background-size: sirve para controlar el tamaño de una imagen de fondo

4. Background-repeat: sirve para controlar si una imagen de fondo se repite

imagen sin repetirse

5. Background-position: sirve para determinar la posición de la imagen de fondo
