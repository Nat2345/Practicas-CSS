Los bordes permiten colocar una linea alrededor de un elemento HTML. Se pueden modificar su color, grosor, estilo y forma, por lo que son utiles para separar o resaltar diferentes partes de una pagina

1. solid: sirve para crear un borde de linea continua

2. Dashed: sirve para crear un borde formado por lineas discontinuas

3. Dotted: sirve para crear un borde formado por puntos

borde de puntos

4. Double: sirve para crear un borde con dos lineas

borde doble

5. Border-radius: sirve para redondear las esquinas del elemento
