FLUJO NORMAL Y DISPLAY



TEORIA EJEMPLOS VIDEO

El flujo normal es la manera en que los elementos se acomodan automaticamente en una página HTML. La propiedad display permite cambiar la forma en que los elementos se comportan y ocupan espacio

1. Block: hace que el elemento ocupe toda la linea disponible

elemento block

2. Inline: permite que varios elementos estén en la misma linea

inline 1 inline 2

3. Inline-block: permite colocar elementos en linea y modificar su tamaño

inline-block
otro

4. None: sirve para ocultar completamente un elemento

5. Flex: sirve para organizar facilmente varios elementos dentro de un contenedor
