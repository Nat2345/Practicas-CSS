El modelo de caja es la forma en que CSS representa y organiza cada elemento de una pagina web. Cada elemento esta compuesto por cuatro partes: contenido, padding, borde y margen. Estas partes permiten controlar el tamaño y el espacio que ocupa un elemento

1. Width: sirve para establecer el ancho de un elemento

ancho de 200px

2. Height: sirve para establecer la altura de un elemento

altura de 80px

3. Padding: sirve para agregar espacio entre el contenido y el borde

espacio interno

4. Border: sirve para colocar un borde alrededor del elemento

elemento con borde

5. Margin: sirve para crear espacio fuera del elemento y separarlo de otros

espacio externo
