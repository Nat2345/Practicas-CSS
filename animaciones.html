ANIMACIONES EN CSS



TEORIA EJEMPLOS VIDEO

Las animaciones en CSS permiten hacer que los elementos cambien de apariencia o posición de manera progresiva. Se utilizan para crear efectos como movimientos, cambios de tamaño, rotaciones y cambios de color

1. Movimiento: sirve para mover un elemento de un lugar a otro



2. Rotacion: sirve para hacer que un elemento gire



3. Cambio de tamaño: sirve para hacer que un elemento aumente o disminuya



4. Cambio de color: sirve para cambiar el color de un elemento durante la animacion



5. Repeticion: sirve para hacer que una animacion se repita varias veces
